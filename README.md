# 12123短信读取应用

## 功能说明
1. 读取短信列表，筛选发件人是12123开头的短信
2. 从短信内容中提取车牌号（如：豫ADS2567）
3. 提取违法行为描述
4. 当检测到相关短信时，手机震动并语音提醒："您的车辆未按规定停放已被记录，请立即驶离"
5. 12123平台其他通知类短信不做解析

## 技术要点
- 需要短信读取权限
- 需要震动权限
- 需要语音合成权限
- 使用正则表达式提取车牌号和违法行为
- 后台服务监控新短信

## 短信格式示例
```
【河南省交警】您的小型新能源汽车豫ADS12345于2025年11月18日9时32分在河南省郑州市建设路（京广路至大学路）路南未按规定停放已被记录，将依法予以处罚。并请立即驶离，未驶离的，将依法拖移，谢谢配合！
```
